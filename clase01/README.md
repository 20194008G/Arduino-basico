# Clase 01 — los sketches que viste en pantalla

Cada archivo es exactamente el código de la diapositiva, listo para copiar y
pegar en el Arduino IDE o en Tinkercad.

| Archivo | Qué hace |
|---|---|
| `clase01_b4_esqueleto.ino` | El esqueleto: `setup()` y `loop()` vacíos |
| `clase01_b4_blink.ino` | Blink: el LED del pin 13 parpadea |
| `clase01_b5_blink_literal.ino` | Blink con los tiempos escritos a mano |
| `clase01_b5_blink_variable.ino` | Blink con una variable de tiempo |
| `clase01_b6_serial.ino` | El Arduino te escribe por el Monitor Serial |
| `clase01_b6_contador.ino` | Una variable que cuenta |
| `clase01_b7_dos_leds.ino` | Dos LEDs que se turnan |

La solución del reto del semáforo no está aquí a propósito: primero inténtalo.
